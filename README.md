LOGO! HMI PRO

Proyecto Android para control local y visualización HMI de PLC Siemens LOGO!.

Incluye:
- Interfaz visual renovada estilo industrial.
- Diagnóstico de conectividad Modbus TCP y Web HMI.
- Lectura FC01 y FC03.
- Escritura FC05 y FC06 con confirmación.
- Visor HMI Web mejorado.
- Build automático por GitHub Actions.

Compilación en GitHub:
1. Sube el proyecto al repositorio.
2. Ve a Actions.
3. Ejecuta "LOGO9 HMI Build APK".
4. Descarga el artefacto APK generado.
